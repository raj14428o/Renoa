# Renoa – Development Branch

This repository uses a simple branch-based workflow.

## Branch Overview

### development
This is the **active development branch**.
- All ongoing development, experiments, and new features happen here
- Code may be unstable or incomplete
- Used for rapid iteration and testing

### master
This branch contains the **stable MVP (Version 1)**.
- Production-ready code
- Includes additional fixes for:
  - Bot / abuse prevention
  - Route-level stability and security issues
  - Other production-only hotfixes
- Only tested and reviewed changes are merged here

## Workflow
- Develop and test features in `development`
- Merge into `master` only when changes are stable and ready for release
