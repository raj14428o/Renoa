# Renoa – Development History (Archive)

This branch contains **historical development work** created prior to the
finalization of the current stable MVP.

It is **not actively maintained** and is preserved strictly for reference,
experimentation history, and architectural context.

### Branch Usage
- **development** → Active development and new feature work  
- **master** → Stable MVP (Version 1) with production-ready fixes  
- **development-history** → Archived development history (read-only)

No new changes should be made to this branch.
